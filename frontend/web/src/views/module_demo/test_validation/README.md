## G6 v5 实现

- 固定依赖 `@antv/g6@5.1.1`，页面进入时动态加载 Canvas 渲染器；其他页面保留 Vue Flow。
- `data.ts`：确定性设备生成、双向流量模拟、园区/设备组聚合、500 明细与 200 动画限制。
- `renderer.ts`：Canvas 设备卡片、园区边界、上下行错位曲线、流动虚线与视口优化。
- 默认 100 台设备按设备组展示；1000/5000 台默认折叠到园区。双击园区/设备组展开，也可从详情操作。
- 搜索覆盖整个数据集，按园区、类型、编号或 ID 匹配；定位时展开所属组，超限时收起其他组。
- 每秒模拟上下行 kB/s，1000 kB/s 显示为 1 MB/s。暂停模拟冻结数值与动画；关闭动画仍更新数值。
- 同时最多 200 条活动链路播放动画，选中与高流量优先；其他链路保留方向和状态。
- 页面离开/文档隐藏时停止计时与动画，重新激活恢复；卸载销毁图实例、监听和计时器。

## 验收与性能记录（2026-10-16）

环境：Windows，本机 Codex 内置 Chromium 浏览器，Vite 开发模式，默认约 1280×720 视口。

| 项目 | 实际结果 |
| --- | --- |
| 模拟数据及聚合逻辑 | 7 项测试通过：三个规模、唯一 ID、双向边、成员和流量统计、离线、500/200 限制 |
| KeepAlive 和文档可见性 | 3 项测试通过：缓存复用单实例、离开停止、返回恢复、卸载清理、加载未完成即离开的竞态保护 |
| 1000 台设备总览 | 管理端内一次切换绘制 40 ms |
| 5000 台设备总览 | 管理端切换绘制 40–96 ms；独立同组件入口一次切换绘制 42 ms |
| 5000 台搜索定位 | 定位 group-209-target-1，自动切换东部园区并展开所属组；一次展开绘制 213 ms |
| 5000 台聚合总览拖动 | 页面 requestAnimationFrame 计数一次观测 60 FPS；仅代表该聚合视图和本机环境 |
| 动态模块加载 | 独立同组件入口一次加载加绘制 1864–4389 ms，浏览器缓存状态非受控，3 秒目标未稳定达到 |

耗时来自页面 performance.now 计数，覆盖绘制与自动适应画布，不含模拟数据生成。FPS 不是浏览器性能追踪报告，未据此声明 500 个明细的动画性能已达标。构建期间机器负载较高，结果不等同于生产基准。

截图与临时验收入口保存在 `frontend/web/output/playwright/`，不作为正式功能入口发布。正式入口仍为菜单「测试验证」。

浏览器另已验证：深色英文显示（g6-dark-en.jpg）、768 像素宽屏幕详情位于画布下方（g6-narrow.jpg）、设备组详情展开。最终检查：10 项测试、类型检查与 ESLint 通过；生产构建无循环分包警告；三处 dist 231 个文件哈希一致。
